    Version 3.0.0¶

    Multiblocks Changes¶

    New: Power Transformer [PT]¶

    An alternative active transformer that can be expanded up to 4 layers for more inputs, or rather, outputs — whatever you like the most.

    All multiblocks were significantly changed for the sake of balance for GTCEu core gameplay aspects.

    1. Robust Alloy Materializer¶

    • Lost parallel hatches in exchange for Perfect Overclock and Batch Mode
    • Definitive removal of laser hatches usage — they are really broken for what an ABS multiblock can do
    • Changed controller overlay

    2. Synthesis Vessel¶

    • No longer performs LCR recipes; only performs its own recipe type
    • Lost machine parallels in exchange for Perfect Overclock and Batch Mode

    3. Large Pyrolysis Oven & Large Cracking Machine¶

    • Changed controller textures

    4. Compact Assembly Line¶

    • Renamed to Expanded Assembly Line [EAL]
    • Lost machine parallels in exchange for Imperfect Subtick Parallels and Batch Mode
    • Entire structure has been reworked; now has layers for each input, implying that it needs a common setup for normal Assembly Lines automation (whether it is AE2 or anything else)
    • Only allows 1 energy hatch, 1 Wireless Optical Receptor, and 1 Maintenance Hatch
    • Its logic now allows recipes without ordered inputs, but they still need a new layer per new input (according to recipe size) (I hope that's clear enough?)

    5. Rock Processing Factory¶

    • Structure modified (again)
    • Allows parallel hatches and has Batch Mode

    6. Industrial Greenhouse & Tree Growing Chamber¶

    • (IG) Lost machine parallels in exchange for Perfect Overclock and Batch Mode
    • (TGC) Renamed to Artificial Conservatory [AC]

    7. Disassembler¶

    • Renamed to Universal Disassembly Machine [UDM]
    • Added a new recipe mode:
    • Component Disassembly → Recipes for decomposing expensive components like Fusion Reactor casings and Fusion Coils (at the moment I write this)
    • Structure has been entirely reworked

    8. Large Gas Collector¶

    • New controller recipe, inlines/fits with the majority of GTCEu IV multis recipes
    • Changed controller overlay
    • Structure has been changed to remove rotor requirement

    9. Matrix Data Relay¶

    • From now on, requires a constant supply of 144 mb/t of PCB Coolant while working
    • Jade Provider: now shows the tier of the respective wireless transmissor placed inside the structure
    • Expanded Data Hatches have an energy usage of 8196 EU/t (1A IV)
    • Each wireless receptor has an energy consumption of 1 full amp of the next tier:
    • LuV Transmissor → 1A ZPM
    • ZPM Transmissor → 1A UV
    • UV Transmissor → 1A UHV
    • Slightly different color on overlay
    • Internal logic fix: controller not switching back to "unformed" state when a part of the structure is removed

    10. Expanded Data Bank¶

    • Removed

    11. Abbreviations¶

    • Some abbreviations were changed to be less "wacky" (is this the right word?)

    Singleblocks Changes¶

    1. Wireless Optical Hatches (Transmissors only)¶

    • They now have a small toggle for custom linking behavior, whether they can connect only to Data Hatches / Expanded Data Hatches inside an MDR multiblock, or any nearby DH / EDH inside its maximum range
    • The range display has been modified to reflect an "Abstract" style with irregular triangles and a small "white bar" that goes up and down inside the render
    • Now they have a custom UI (using Minecraft Screen, without LDLib/ModularUI) for management of their functions, such as showing the range display and linked hatches, plus a cooldown for any new re-scan (3s)
    • Transmissors & Receptor: new overlays made by tomoko3seven/sqvizers

    2. Expanded Data Access Hatches & Configurable Cleaning Maintenance Hatch¶

    • Added their respective emissive overlays

    Internal changes & bugfixes¶

    1. Immersive Vehicles init issue¶

    Fixed a client init issue with Immersive Vehicles during mod loading (Issue #3 - GitHub).

    2. Client-side crash with disabled features¶

    Fixed a client side crash issue where, if the disassembler, universal circuits, or expanded data hatches were disabled, the game would crash with the following message, due to them not existing as "icons" for EF's creative tabs:

    [Render thread/ERROR]: Caught exception during event RegisterEvent dispatch for modid extendedfeatures
java.lang.RuntimeException: Unexpected error while registering entry extendedfeatures:extendedfeatures_multiblocks to registry minecraft:creative_mode_tab

    3. Massive folder renaming and refactor¶

    4. Removed laser multiblock classes¶

    CoilLaserMultiblock & WorkableLaserMultiblock classes were permanently removed due to them no longer working (and I'm lazy to fix it xd)
