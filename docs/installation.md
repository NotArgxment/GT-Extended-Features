# Installation

## Requirements

- Minecraft **1.20.1**
- **GTCEu Modern** (and its dependencies)
- A mod loader compatible with the mod (Forge/Fabric as specified by the release)

## Steps

1. Download the latest release from [Modrinth](https://modrinth.com/mod/gtm-extended-features)
   or [CurseForge](https://www.curseforge.com/minecraft/mc-mods/gtm-extended-features).
2. Place the `.jar` file in your `mods/` folder.
3. Make sure all required dependencies are installed.
4. Launch the game.

## Updating

Replace the old `.jar` with the new one. Back up your world before updating between major versions.
