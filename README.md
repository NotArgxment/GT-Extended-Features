## GTM Extended Features

Addon for GTCEu Modern 1.20.1 designed to provide quality of life changes for the player and tools for modpack developers

## Download links

**Modrinth (3.0.0):** https://modrinth.com/mod/gtm-extended-features

**Curseforge (3.0.0):** https://www.curseforge.com/minecraft/mc-mods/gtm-extended-features
